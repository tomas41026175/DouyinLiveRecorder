    錄製通知（Discord）

    主播開始/結束錄製時發到 Discord 頻道
    Discord 頻道 → 編輯頻道 → 整合 → Webhook → 新增 Webhook → 複製 Webhook URL 貼上。 若 Discord 在你的網路被牆，填上可連外的 proxy（留空則走系統/環境代理）。

    Discord 控制頻道（新增/移除主播）

    在指定的 Discord 頻道用文字指令新增/移除監控中的主播，不用開控制台。需要一個 Discord Bot（跟上面的錄製通知 Webhook 是不同東西）。
    建立方式：Discord Developer Portal → New Application → Bot → 複製 Token；Bot 設定頁打開「MESSAGE CONTENT INTENT」； 用 OAuth2 URL Generator（scope 勾 bot，權限勾 Send Messages + Read Message History）產生邀請連結把 bot 加進伺服器； 頻道 ID 在 Discord 開「開發者模式」後右鍵頻道複製。
    指令：新增 <網址或抖音號> [主播名稱]、移除 <主播名稱或網址片段>、清單（都要加上面設定的前綴，例如 !新增）。
